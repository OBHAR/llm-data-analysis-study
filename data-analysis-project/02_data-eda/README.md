# 02_data-eda

이 폴더에는 따릉이 일별 대여량 2023~2025년의 품질 점검과 탐색적 분석을 재현하는 노트북이 있습니다.

## 실행 환경

Python 3와 Jupyter 환경에서 `pandas`, `numpy`, `matplotlib`, `openpyxl`을 사용합니다.

## 원자료 배치

노트북이 안내하는 파일명에 맞춰 원자료를 `data/raw`에 두거나, 노트북의 `DATA_DIR` 설정을 실제 경로로 바꾸면 됩니다. 원자료는 공개 저장소에 별도 업로드하지 않고 분석자가 내려받은 파일을 사용합니다.

노트북은 강수량 공란을 원본 상태로 보존합니다. 공란을 0으로 둔 결과는 민감도 비교에만 사용하며, AWS 자료는 ASOS 대체값으로 사용하지 않습니다.
